# One-site occlusion

For a selected site, numeric values are set to 0, numeric missingness indicators to 1, and categorical indices to 0. Global features remain unchanged and the learned site identity mechanism remains present. This is masking of site features, not deletion of an anatomical token. The reconstructed aggregation script computes absolute and relative importance and Spearman correlation across aligned 14-site Internal100 and External80 vectors. Target rho is 0.956043956043956 (manuscript 0.956; P approximately 9.47e-08).
