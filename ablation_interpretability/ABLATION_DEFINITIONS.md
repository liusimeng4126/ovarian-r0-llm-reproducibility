# Prespecified Model 3 ablations

- **No site identity:** removes learned site identity embeddings while retaining site features.
- **No longitudinal change:** removes longitudinal change features while retaining other inputs.
- **POST only:** retains post-treatment site observations and the corresponding features.
- **Mean pooling:** replaces additive attention pooling with mean pooling.

These are the four manuscript variants; exploratory variants are excluded.
