# Model 2 RRS v3.3

The executable implementation and frozen JSON are in `model2_rrs/`. Higher RRS means greater non-R0 risk. The final classification is `RRS < 2.5 -> R0` and `RRS >= 2.5 -> non-R0`. The rules correspond to the manuscript Supplementary Table S2, including risk-domain mapping, component scores, highest/second-highest handling, multidomain combinations, extreme-difficulty features, treatment response, residual burden, and protective response components.
